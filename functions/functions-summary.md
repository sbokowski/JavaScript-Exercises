# JavaScript Functions

## What Are Functions?

A function is a reusable block of JavaScript code designed to perform a specific task.

Functions help organize code, reduce repetition, and make programs easier to maintain.

## Basic Function Example

```javascript
function greet() {
    console.log("Hello, welcome to JavaScript!");
}

// Call the function
greet();
```

## Important Things to Know

- `function` defines a new function.
- `greet` is the function name.
- `{ }` contains the code that runs.
- `greet()` calls or executes the function.
- Functions can be called multiple times.
- Functions can also accept parameters and return values.

## Functions and Loops

Functions can be used inside loops to repeat tasks without rewriting code.

**Remember:** Functions make JavaScript code reusable and organized.
